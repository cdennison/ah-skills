# Roadmap

1. **Connect skills.sh** — requires a Vercel token to authenticate/integrate with skills.sh.
2. **Cross-index skill mapping** — map a single skill across multiple indexes (e.g. Claude marketplace, skills.sh) and use presence/consistency across indexes as a signal of skill quality.
3. **Split Streamlit into separate backend/frontend** and deploy Qdrant to production (e.g. AWS). A quick cost sanity check put hosting under $100/month, even via a paid SaaS option.
