# Registry & Manifest Schemas

Two YAML files live under `registry/`:

- `skill-directories.yml` — the human-curated registry. Holds metadata, tags, license, evidence trail.
- `scan-manifest.yml` — the machine-consumable manifest. Stripped down for the agentic highway scanner.

`scan-manifest.yml` is **derived**. Never edit it by hand; rebuild via `scripts/build_scan_manifest.py`.

## skill-directories.yml

Top-level shape:

```yaml
version: 1
generated_at: 2026-05-08
entries:
  - name: anthropics-skills
    url: https://github.com/anthropics/skills
    kind: collection
    ref: main
    scan_paths:
      - skills/*/SKILL.md
    description: ...
    license: Apache-2.0
    tags: [official, anthropic]
    last_verified: 2026-05-08
    requires_crawler: false
    notes: optional free-form text
```

### Field reference

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `name` | string | yes | Lowercase, hyphenated. For GitHub: `owner-repo`. For hosted: hostname stem (`claudemarketplaces-com`). Must be unique within the registry. |
| `url` | string | yes | Canonical https URL. No trailing slash. |
| `kind` | enum | yes | One of `collection`, `individual`, `marketplace`, `awesome-list`, `vendor-skills`, `registry`. |
| `ref` | string | no | Git ref (branch or tag) the scanner pins to. Empty string for hosted (non-git) sources. Default `main` for git sources. |
| `scan_paths` | list[str] | yes | Globs relative to the directory root pointing at `SKILL.md` files. Empty list for crawler-mode sources. |
| `requires_crawler` | bool | no | When true, the scanner uses a web crawler instead of git tree walks. Default false. |
| `description` | string | recommended | One-sentence summary. |
| `license` | string | no | SPDX identifier or short label. |
| `tags` | list[str] | no | Free-form lowercase tags. Reserved tags: `official`, `vendor`, `community`, `1k+`, `large`, `cross-tool`, `vetted-<year>`. |
| `last_verified` | ISO date | yes | Set by `merge_candidates.py` to the day a vetter confirmed reachability. |
| `notes` | string | no | Anything that belongs in the registry but not in the manifest. |

### Validation rules enforced by `validate_registry.py`

- `version` is `1`.
- Every entry has the required fields.
- `name` is unique within `entries`.
- `kind` is one of the allowed values.
- `url` matches `^https://[^\s]+[^/]$`.
- `last_verified` parses as an ISO-8601 date.
- If `requires_crawler` is false, `scan_paths` must be non-empty.

## scan-manifest.yml

Shape consumed by the agentic highway scanner:

```yaml
version: 1
generated_at: 2026-05-08
targets:
  - name: anthropics-skills
    url: https://github.com/anthropics/skills
    ref: main
    kind: collection
    scan_paths: [skills/*/SKILL.md]
    requires_crawler: false
```

Fields are a strict subset of the registry: `name`, `url`, `ref`, `kind`, `scan_paths`, `requires_crawler`. Generated by `build_scan_manifest.py`. The scanner is free to ignore unknown top-level keys, so the `version` and `generated_at` envelope is non-breaking.

## Deferred queue

`registry/deferred.yml` is appended to by `merge_candidates.py` when a vetter returns `decision: "defer"`. Same envelope as the registry, plus a `reason` field per entry. The next research run reads this file before dispatching scouts so it can re-evaluate deferred entries cheaply.
